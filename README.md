# Voyage — 旅するフランス語 🗼

フランス旅行を最高に楽しむための、フランス語フレーズ & フランス文化アプリ。

**ビルド不要・依存ゼロ。`index.html` をブラウザで開くだけで動きます。**

```bash
# ローカルで開く場合
python3 -m http.server 8000
# → http://localhost:8000
```

## できること

- 🌅 **ホーム** — パリの夜明けヒーローと「今日のフレーズ」(日替わり・音声つき)
- 💬 **フレーズ集** — 7カテゴリ83句。仏語・日本語・カタカナ発音・🔊ネイティブ音声(Web Speech API)・☆お気に入り
- 📖 **文化ガイド** — マナー・食・暮らし・旅のコツ、旅情をかき立てる読み物14本
- 🎯 **クイズ** — 意味当て & リスニングの10問。ベストスコア記録、満点で紙吹雪
- 🌙 ライト/ダークテーマ(ダークはパリの夜に変わります)、モバイル対応、reduced-motion 配慮

お気に入り・スコア・テーマは localStorage に保存。オフラインでも動作します
(音声はブラウザ内蔵のフランス語音声合成を使用)。

## つくりかた

このアプリはマルチエージェント開発で生まれました。
設計は Claude Fable 5、実装は Claude Opus(アプリ本体・デザインシステム)と
Claude Sonnet(フレーズデータ・文化記事・クイズエンジン)の分業です。
詳しい設計とデータ契約は [DESIGN.md](DESIGN.md) を参照してください。

## ファイル構成

```
index.html      アプリシェル
css/style.css   デザインシステム(CSS変数でテーマ管理)
js/app.js       ナビ・音声・お気に入り・描画
js/quiz.js      クイズエンジン
data/phrases.js フレーズデータ(7カテゴリ83句)
data/culture.js 文化ガイド記事(14本)
```

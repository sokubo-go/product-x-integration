# Voyage — 旅するフランス語 & イタリア語 🗼🇮🇹

旅行を最高に楽しむための、フレーズ・レッスン・文化・観光ガイドのアプリ。
フランス語版とイタリア語版が対になっています。

**ビルド不要・依存ゼロ(地図の Leaflet は同梱)。`index.html` をブラウザで開くだけで動きます。**

```bash
# ローカルで開く場合
python3 -m http.server 8000
# → http://localhost:8000
```

## できること

### アプリ本体(index.html / app-it.html)
- 🌅 **ホーム** — 朝焼けのヒーローと「今日のフレーズ」(日替わり・音声つき)
- 💬 **フレーズ集** — 場面別カテゴリ。原文・日本語・カタカナ発音・🔊ネイティブ音声(Web Speech API)・☆お気に入り・🪧見せるカード
- 📚 **レッスン** — ライトナー式SRS(間隔反復)+ 想起フリップ + シャドーイング + シーン会話ドリル + 基礎文法12ユニット + 単語帳
- 📖 **文化ガイド** — マナー・食・暮らし・旅のコツの読み物
- 🎯 **クイズ** — 意味当て & リスニングの10問。ベストスコア記録、満点で紙吹雪
- 🌙 ライト/ダークテーマ、モバイル対応、reduced-motion 配慮

### 観光ガイド(guide.html / guide-it.html)
- 🗺️ **パリ編** — ヴェルサイユ・パリ・セーヌの順路・見どころ・物語・使える一言
- 🏛️ **イタリア編** — ローマ・バチカン・サントリーニ(ギリシャ語フレーズつき)
- 現地マップ(OpenStreetMap + Leaflet)、ヴェルサイユのイラストマップ(オフライン用)、訪問チェックと進捗

お気に入り・学習状況・スコア・テーマは localStorage に保存。オフラインでも動作します
(音声はブラウザ内蔵の音声合成、写真は Wikipedia から実行時取得でオフライン時は下地表示)。

## つくりかた

このアプリはマルチエージェント開発で生まれました。
設計は Claude Fable 5、実装は Claude Opus(アプリ本体・デザインシステム)と
Claude Sonnet(フレーズデータ・文化記事・クイズエンジン)の分業です。
詳しい設計とデータ契約は [DESIGN.md](DESIGN.md) を参照してください。
